# 工作記錄系統 v1.1.2

正式版：新增獨立跨專案甘特式時間軸、共用功能選單，並同步支援專案與節點期間資料。


## v1.1.2 變更
- 專案節點支援預計開始、預計完成、實際開始、實際完成四日期，未取得預計時程時可留空。
- 設定頁與跨專案甘特圖共用 project_schedules.config/nodeDates，並同步 project_schedule_nodes。
- 甘特頁移除載入成功提示、標題上移、內容貼齊左側。
- 修正由甘特頁返回設定、專案總覽等功能時的 Hash 導覽。


## v1.1.2 修正
- 日期座標採本地日期計算，不再因 UTC 時區提前一天。
- 甘特主畫面取消左側保留邊距。
- 專案／節點欄固定顯示。
- 移除甘特頁標題。
